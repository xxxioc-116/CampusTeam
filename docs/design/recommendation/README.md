## 使用说明

1. 本目录内容均为设计素材，不是报告正文；正式章节由主文档统一撰写。
2. `diagrams.md` 中的 Mermaid 图在 GitHub 可直接渲染；报告阶段导出为 PNG 后放入 `docs/design/assets/recommendation/`，按 X-Y 编号，图题置于图下方，五号宋体加粗。
3. 表格在报告中转为三线表，表题置于表上方，五号宋体加粗。
4. 公式在报告中转为 Word 公式对象，保留本文的符号约定与算例。
