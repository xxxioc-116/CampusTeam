# CampusTeam 软件设计规格说明书交付

本目录保存软件设计规格说明书及前端设计图源文件，便于评审、答辩和后续修订。

## 主要文档

- `CampusTeam_软件设计规格说明书.docx`：合并后的软件设计规格说明书。

## 前端设计图

- `frontend-components.png`：前端组件及依赖关系。
- `page-navigation.png`：页面导航与权限边界。
- `profile-save-sequence.png`：能力画像保存时序。
- `project-application-activity.png`：项目浏览与申请流程。
- `frontend-deployment.png`：前端构建、联调与部署流程。

## 页面原型

- 登录注册页面
- 能力画像页面
- 项目大厅页面
- 团队能力矩阵页面
- 推荐结果页面
- 邀请收件箱页面

前端路由表和页面状态表收录在规格说明书第 8 章。第 4 章接口设计采用统一编号、Token 认证格式、错误响应结构和权限表；各业务接口的最终语义由对应模块负责人共同复核。
