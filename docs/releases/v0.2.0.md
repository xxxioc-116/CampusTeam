# CampusTeam v0.2.0 Beta

## Features

- Vue 3 项目大厅、登录、能力画像、团队矩阵、缺口和推荐页面。
- 真实后端画像持久化、团队需求、能力矩阵、能力缺口和 Top-K 推荐 API。
- 可配置五维加权推荐、稳定排序、贡献解释和固定种子对比实验。
- 申请、邀请、接受与成员能力重算的真实 Token 联调闭环。
- 管理员统计 API、核心模块覆盖率门禁和覆盖率报告产物。

## Bug Fixes

- 修复推荐接口中 `is_staff` 绕过业务角色权限的问题。
- 修复画像编辑取消后未恢复服务器快照的问题。
- 修复依赖安装脚本、CI YAML 引号和演示环境变量清理问题。

## Known Limitations

- 前端尚无邀请收件箱，候选人接受邀请由真实 API 完成。
- 管理员统计与团队健康度已有 API，尚未提供完整可视化页面。
- 推荐计算随候选人数近似线性增长，当前 1000 人规模基线约 400ms 内。

## Verification

- 后端、前端、推荐、集成、治理、SonarCloud 和聚合质量门禁全部通过。
- 全局后端覆盖率门禁 80%，核心 Service/API 门禁 60%。
- 真实浏览器联调使用 Playwright、真实 Django 后端和临时 SQLite 数据库。
