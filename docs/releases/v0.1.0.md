# CampusTeam v0.1.0 Alpha

## Features

- Django/DRF 后端骨架、环境变量配置和健康检查。
- 用户注册登录、Token 认证、三类角色及对象级权限。
- 项目、技能、团队、申请、邀请和审计数据模型。
- 初始迁移、演示数据命令及自动化测试。

## Bug Fixes

- 统一业务管理员权限为 `User.Role.ADMIN`，避免 `is_staff` 旁路。
- 重复申请、重复邀请和重复状态迁移均返回明确业务错误。

## Known Limitations

- 前端、推荐算法和团队分析模块尚未接入。
- 默认开发数据库为 SQLite；部署环境需配置 MySQL 并重新执行性能测试。

## Verification

- `python manage.py check`
- `python manage.py makemigrations --check --dry-run`
- `python manage.py test core tests`
