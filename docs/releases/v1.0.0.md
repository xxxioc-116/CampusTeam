# CampusTeam v1.0.0

## Features

- 完整 P0 业务：认证、画像、项目、团队、申请、邀请、权限与审计。
- 完整 P1 主链路：团队能力矩阵、能力缺口、可解释 Top-K 推荐和时间/目标匹配。
- 团队健康度五维评分、风险预警与管理员运营统计 API。
- 真实浏览器答辩链路：注册、登录、项目检索、画像保存、矩阵、推荐、邀请、接受、重算和健康度。
- 100/500/1000 候选规模性能报告和固定 SQL 查询数的 N+1 回归守卫。

## Bug Fixes

- 修复 benchmark `--out` 可写入任意路径的安全问题；输出被限制到 `artifacts/` 下的纯文件名。
- 修复业务管理员权限、前端取消编辑、依赖安装和测试环境清理问题。
- 所有曾被 Review 阻断的问题均经过修改、重新检查与非作者批准。

## Known Limitations

- 当前为课程项目单节点演示版本，未完成生产级高可用、监控和容量规划。
- 前端尚无邀请收件箱、团队健康度面板和管理员统计页，相关能力通过真实 API 演示。
- SQLite 性能数据仅用于回归比较，不代表 MySQL 生产容量承诺。
- 推荐计算为内存内线性扫描，候选规模显著扩大后应增加离线索引或召回层。
