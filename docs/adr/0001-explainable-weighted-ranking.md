# ADR 0001 采用可解释加权评分作为推荐基线

- 状态：Accepted
- 日期：2026-10-25

## 背景

课程项目需要在有限周期内交付可运行、可测试、可答辩的智能组队功能。深度模型会增加数据规模、训练环境和解释成本。

## 决策

第一版采用五维加权评分：能力互补 0.35、技能匹配 0.25、时间匹配 0.20、目标一致 0.10、经历匹配 0.10。结果同时返回每一维得分、主要缺口贡献和风险提示。

## 后果

- 优点：实现风险低、易于单元测试、权重可审计、推荐理由可直接展示。
- 代价：权重依赖人工设定，需通过人工标注小样本和对比实验校准。
- 后续：只有在 v0.2.0 基线稳定后，才评估学习排序或聚类方案。
